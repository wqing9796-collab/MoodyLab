# MoodyLab

**Cinematic Color Grading Plugin for Adobe Photoshop**

MoodyLab is a professional color grading plugin that brings cinematic film tones to your photos with just one click. Designed for portrait, wedding, and lifestyle photographers who want a distinctive moody aesthetic.

🌐 **Website**: [https://camer.xin/moodylab.html](https://camer.xin/moodylab.html)

---

## Features

- **One-Click Cinematic Tones** — Instantly apply professional film-inspired color grading
- **Designed for Portraits** — Optimized for skin tones across all ethnicities
- **Wedding & Lifestyle Ready** — Perfect for wedding photography, street portraits, and editorial work
- **Real-Time Preview** — See the effect before applying
- **Non-Destructive Editing** — Works with Photoshop's adjustment layers
- **Lightweight & Fast** — No lag, no bloat
